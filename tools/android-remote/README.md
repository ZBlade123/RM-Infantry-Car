# RM步兵战车 手机蓝牙遥控（Android v2.1）

双摇杆横屏遥控器：左手开车、右手打云台、中间停车/发射，界面上直接写着中文提示，装到手机上不用讲解也能上手。

- 包名 `com.rm.car`，minSdk 21 / targetSdk 34，强制横屏，常亮
- 产物：`桌面\RM步兵战车遥控.apk`（v2.1，24.4 KB）
- 源码：`src\com\rm\car\MainActivity.java`（单文件，纯系统 API，无 Gradle/AndroidX）
- 构建：`powershell -ExecutionPolicy Bypass -File .\build.ps1 -OutApk "<输出目录>\RM步兵战车遥控.apk"`
- 连接：蓝牙 **SPP**（HC-05/JDY31），先在系统设置配对（PIN 1234）

## 每个控件干什么

| 控件 | 位置 | 作用 | 线上指令 |
|---|---|---|---|
| **行驶摇杆** | 左下大圆 | 推前=前进、拉后=倒退、左右=横移（麦轮）；推得越远越快，松手刹停 | 每 50ms 发 `v vx vy wz`，松手发 `x` |
| **左转/右转** | 摇杆下方 | 按住原地自转，**可以和摇杆同时按**（边走边转） | `v` 的 wz=±speed |
| **云台摇杆** | 右下大圆 | 左右=偏航（炮塔方向），上下=俯仰（往上推=抬头） | `y deg10` / `s deg10`，节流 60ms |
| **云台回中** | 右下角 | 偏航+俯仰一起回到 90° | `s 900` + `y 900` |
| **跟随** | 右下角 | 底盘跟着云台朝向走（需要底盘角度环） | `follow 0` / `follow 1` |
| **停 车** | 正中大红键 | 摇杆归零 + 立刻清速度，异常先按它 | `x` |
| **发 射** | 正中绿键 | 三连发（AEG 单发会卡半压缩位） | `f` |
| **单发** | 绿键下方 | 只打一发，点射用 | `f1` |
| **慢/中/快** | 底部 | 摇杆最大输出 300/600/1000，上场先慢后快 | 本地量 |
| **查状态** | 底部 | 立刻读一次云台角度 | `g` |
| **握手** | 底部 | 确认链路，回 `RM-INFANTRY-CAR` 即通 | `p` |
| **协议** | 底部右 | `RM`（本仓库固件）与 `@`（RS05/JDY31 桥接固件）互切 | — |
| **说明** | 顶部 | 弹出上面这张表的通俗版本 | — |

## @ 协议模式

切到 `协议 @` 后界面变成 8 方向键 + `PING / ARM / DISARM`，按住方向每 200ms 重发、松手补 `@S`。
顺序：`PING`（等到 `PONG RS05-BT/1`）→ `ARM`（可能先 `PENDING ARM`，等到 `OK ARM`）→ 行驶。

## 联调步骤

1. 手机配对 HC-05 → App 选设备 → `连接` → 顶栏变「车已就绪」。
2. 点 `查状态`，拖右摇杆时看「偏航/俯仰」数字是否跟手（同时验证云台与回传）。
3. 架空：前推四轮同向、左推横移、左转/右转左右反号。
4. 落地先用 `慢 300` 跑直线，再上 600/1000。

## 设计取舍

- **50ms 一帧速度**：固件 10ms 一环、链路超时 500ms；`v 1000 1000 1000\r\n` ≈ 20 字节 × 20 = 400 B/s，9600 波特率（≈960 B/s）够用一半余量。
- **松手发 `x`**：立刻清固件里的目标速度，比等加速度斜坡自然停更快。
- **云台节流 60ms**：总线舵机一帧 `#001P1500T200!` 15 字节，拖太猛会顶住 115200 发送缓冲。
- **状态回填**：每 2 秒自动 `g`，用车上回的真值覆盖本地 yaw/pitch，重连/切档不会出现「屏幕 90°、实际 30°」。
- **双摇杆而不是按钮阵列**：摇杆是拇指连续量，打点、绕柱、边走边瞄都是连续动作，按钮做不到。

## 已知限制

1. 只能 SPP 经典蓝牙；iPhone 连不上（iOS 无 SPP），改用 `tools\pc_remote.ps1`。
2. 无图标资源，系统默认图标。
3. 首次连接会弹 Android 12+ 的「附近的设备」授权。
4. 小屏（小于 5.5 寸）顶栏按钮会偏挤，建议 6 寸以上或平板。
