# 整车接线总表（旧控制板映射 v3.8，2026-11-05）

本页是当前接线标准，对应 `rm_config.h`：F103C8T6、板载两颗 TB6612、四个 310 编码器电机、60mm 麦轮、总线二维云台。引脚沿用项目记录；本目录没有可重新核验的 PCB 网络表原件，**动刀前必须实测通断**。新采购电机、舵机不能仅按外观认定与旧型号一致。

**适用范围仅限旧 F103/TB6612 控制板。** 桌面另有 `降压PCB1_2026-11-03.zip`；其飞针文件显示新板 H1=GND/5V/PB0、H3=GND/5V/PB1、H4=PB10/PB11/GND/3.3V，与本页对旧板的 H1/H2 名称及固件板级映射不能混用。新板 H2 网络未命名，且无原理图；按 [配件与 PCB 核对](配件与PCB核对.md) 完成识别前，不要接电池或照本页接线。

## 1. 电源树

```text
单块 2S LiPo XT60 正极
  -> 主保险（靠近电池，现有 15A 需校核）
  -> 直流额定总开关 -> XT60 分电板正极
       +-> H2 正极 -> TB6612 VM -> 四个底盘电机
       +-> MP1584 #2 IN+ -> OUT+ 调至 5.0V -> H1 正极
       +-> 舵机独立降压/BEC IN+ -> 舵机 V+
       +-> 发射支路保险（需补）-> MOS IN+

电池负极 -> 分电板负极
       +-> H2/H1 GND、两路降压 IN-/OUT-、主控 GND
       +-> 舵机 GND、MOS IN-/信号 GND
```

- 两块电池**轮换备用**，不直接串联或并联；禁止 3S。2S 标称 7.4V、满电 8.4V。H2 丝印“12V”只是网名，不会升压，不能供要求 12V 的图传。
- H1 输入 **5V**，经板上 LDO 得 3.3V；MP1584 #2 不要调成 3.3V 后接 H1，不盲目向板上 3.3V 网络注电。
- MP1584 #1 只是云台电源的**待验证候选**。先查舵机额定电压与两轴启动/堵转电流，再做带载压降、温升测试。“3A”标签不是持续供电保证，不足就换足额 BEC，不并联两块模块输出。
- 价格表实购 3 个 MP1584；本旧板方案最多将一只作为备用/后续支路候选。第三只不需要为“用完”而接入，不得并联模块输出。
- 信号共地，但电机/波箱大电流回线直接回分电板，不穿过主控地线或杜邦线。
- BB 响按产品定义接 **2S 平衡口 B-/B1/B2**，先量相邻针电压，禁止反插；建议先设单节 3.5~3.6V 报警并实测，响就停车断电。它**不自动切断电池**，主开关关掉后也要拔下报警器。需无人值守保护应另加合适的低压断电装置。
- BC-4S15D 必须核对说明书支持该电池的 **2S LiPo 平衡充电**及接头/充电电流；充电时电池从车上拔下，在防火环境看护充电，鼓包、破损电池停用。

## 2. 信号引脚（当前总线版）

| 功能 | 引脚/接口 | 备注 |
|---|---|---|
| RR / FL / RL / FR PWM | PA0 / PA1 / PA2 / PA3 | TIM2，1kHz |
| FL IN1/IN2 | PA4 / PA5 | 轮号 0 |
| RL IN1/IN2 | PA6 / PA7 | 轮号 1 |
| RR IN1/IN2 | **PA15 / PB11** | 轮号 2；隔离原 PB10 到 RR IN1 走线后飞线 |
| FR IN1/IN2 | PB12 / PB13 | 轮号 3 |
| 云台总线 TX | **PB10** | USART3，115200 8N1，开漏，只发不读回 |
| 云台两轴 | Yaw ID=1，Pitch ID=2 | 仅适用于所附松甲 ASCII 协议 |
| 外置发射 MOS 信号 | PB14 | 3.3V 高有效，软件 PWM；不是板载 MOS 的负载输出端 |
| HC-05 TXD / RXD | PA10 / PA9 | USART1，9600；模块供电按说明书 |
| ST-Link SWDIO / SWCLK / GND | PA13 / PA14 / GND | 保留 SWD，PA15 的 JTAG 已关闭 |
| 舵机 PWM 备用 | PB0 / PA8 | **总线模式不使用**，不接总线舵机 |
| 编码器 A/B | 当前未接 MCU | 有排线不等于有速度闭环 |
| PB1 ADC | 可选，默认关闭 | 仅按第 6 节分压改造后使用 |

**PB11 是 RR 方向脚，不接视觉 TX！PA2/PA3 是电机 PWM，不接串口设备。** `RM_ENABLE_VISION=0` 且代码禁止启用。视频图传可独立工作，但不占用这些信号脚。

## 3. 云台接法与改板

1. 确认实物型号、供电、逻辑电平、角度行程、波特率、位置帧与改 ID 帧。磁编码不证明兼容 `#001P1500T0200!`，RS485/CAN 舵机不能直连 PB10。
2. **全车断电并拔下电池和下载器**，量 PB10 到 TB6612 RR IN1 的通断。确认网络后才隔离该走线，隔离后量 PB10 与 RR IN1 断路。PA15 飞到驱动侧 RR IN1，PB11 保留为 IN2。先查飞线短路，再验证电机，最后接云台。
3. 对兼容单线 TTL 总线：PB10 开漏接总线，两舵机信号**共线**、供电**并联**，不能电源串联。按厂家电路确认上拉/接口板；缺上拉时，在电平匹配确认后补合适上拉到 3.3V（例如 4.7kΩ 起测并检查波形），不得拉到电池电压。更高逻辑电平或不明回包电路使用匹配接口板。
4. 用限流电源、厂家调试器逐颗设 ID，卸下舵盘/负载。主控会自动向两个 ID 发回中指令，用主控改 ID 也不能假设舵机静止。仅确认兼容后用 `id 1` / `id 2`，每次总线上只留一个舵机。
5. 默认跨度 180°、中心 90°是待标定值，不按“总线版”猜角度。核对后改 `RM_SERVO_SPAN_DEG`、中心与限位。上电先请求中心，总线首次回中 `T=1500ms`，不再人为扫下限。没有角度反馈，实际速度须实测。

## 4. 发射 MOS（仅适用于已核实的低端开关模块）

```text
分电板+ -> 支路保险 -> MOS IN+
分电板- ------------> MOS IN-/GND
MOS OUT+ ------------> 电机+
MOS OUT- ------------> 电机- （开关节点，不是系统 GND）
PB14 ----------------> 模块 SIG/IN（3.3V 高有效）
主控 GND ------------> 模块信号 GND
```

**禁止把电机负极/MOS OUT- 再接电池负极，否则旁路 MOS，电机会常转。** 不同模块端子/拓扑不同，先核对说明书。

- 主控复位、输入高阻时也须关断；核对模块自带下拉，没有则按输入电路补下拉（常用 10kΩ）。散热片先确认金属背面是否带电，必要时用绝缘导热垫。
- 两只 1000µF/25V 分别放在 H2 的 VM-GND 与 MOS 的 IN+-IN- **输入电源端**，注意极性；不将大电解跨在 PWM 电机输出两端。104 瓷片用于电机刷端高频抑噪。
- SS54 约 5A，**不能默认适用于未知波箱电机的续流电流**。按启动/堵转电流、PWM 续流与热条件选型，检查模块自带钳位是否足额。续流二极管阴极（条纹）接电机+、阳极接 OUT-；**不把单只 SS54 跨在可反转底盘电机两端**，否则某方向短路。
- 先用匹配电源的小功率假负载验证 SIG=0、开机、复位时关断。70ms 脉冲不能靠普通万用表可靠判断，用示波器或受控测试；未确认就不接波箱。

## 5. 线材、保险与 6P 排线

| 材料 | 用途与限制 |
|---|---|
| 14AWG + XT60 | 电池、主保险、总开关、分电板主干 |
| 18AWG | 单个底盘电机/驱动候选；波箱按峰值、长度、端子额定选择，必要时用 14AWG |
| 22AWG | 低电流逻辑供电；舵机电源不能按信号线选细线 |
| 杜邦线 | 低电流信号/临时调试，不作电机/波箱/舵机大电流线 |
| XH2.54-PH2.0 6P 反向线 ×5 | 四轮各一根、一备；**不保证线序通用** |

6P 每根均在断电时标记两头针 1 朝向，用通断档记录 **M+/M-/编码器 VCC/GND/A/B** 映射；对照手册与 PCB 实测后才插。目前无可靠实物逐针证据，不伪造 1~6 针号。编码器不能误供电池电压；输出电平确认后才能接 MCU。

15A 是现有片，**不是已验证额定方案**。按四轮与波箱同时工作电流、启动脉冲、保险时间-电流曲线和线束/端子额定校核。保险保护线束短路，不保证保护半导体或防过放；补支路保护，不可因熔断直接换大。开关看 **DC** 额定，不把 AC 16A 当作直流 16A。板载小开关、DC005 不承载整车动力。

## 6. 分阶段验收（不通过就停）

以下步骤按本页所述旧控制板编写。新 PCB 必须先完成 [配件与 PCB 核对](配件与PCB核对.md) 的网络/额定核验。

1. 断电查短路、热缩、保险、隔离与飞线。PCB 用尼龙柱架高，电池防刺穿固定；U 支架固定四电机，麦轮按套件成 X 型，不刮螺丝。
2. 不接负载分别调降压：逻辑 5.0V，云台按实物额定。确认总开关能切断所有动力支路。
3. 只接逻辑 H1，量 3.3V、烧录后 `p` 看 PONG。下载器 3.3V 电源输出不与外部供电硬并，VTref 按下载器说明处理。
4. 架空，云台/波箱断开，H2 接 2S。量驱动 VCC/STBY/VM。`m 0 200` 后 `x`，依次测 1、2、3；**不手捏轮子堵转**。方向用 `flip` 校准、`cal` 记录，持久化须改宏重编译。
5. 短时低速验证前后、平移、旋转与温升。65% 占空不是限流，15A 主保险保护不了单通道 TB6612 的过载。
6. 云台先单颗空载，再两轴同时运动测压降/温升；从 `y 950`、`s 950` 小步开始，逐步标软限位，不直接扫满行程。`g` 是指令估计值，不是编码器实测。
7. 波箱完成假负载、续流、保险校核后才接电机，按厂家允许的空载/空仓方式短测，护目镜、安全朝向，卡住立即断电。
8. 架空发送运动指令后停止所有控制/心跳，**保持车供电**；500ms 超时后加调度延迟应停车并关发射。另测 `x`、总开关和低压报警。拔电池不能证明失联保护。

可选 ADC：上臂 33kΩ、下臂 10kΩ（1%），PB1 对地 100nF；满电 8.4V 时约 1.95V，先实测校准再开 `RM_ENABLE_VBAT`。禁止旧 10k/10k 的 4.2V 接法。默认关闭时固件不提供低压停机。
