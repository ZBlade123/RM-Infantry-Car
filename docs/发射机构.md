# 发射机构接线与验收（v3.7）

本次清单只明确双 MOS 模块，没有明确波箱电机、传动件与弹仓。旧项目记录为组委会提供波箱，需核对实际交付；不能仅凭“480”猜轴径、峰值电流、齿轮或循环时间。

接线严格采用 [接线总表第 4 节](接线总表.md#4-发射-mos仅适用于已核实的低端开关模块)。适用于已确认的低端开关模块：MOS IN-/信号地与主控共地，**OUT- 只接电机负极，绝不能再接系统地**。双 MOS 一般是并联开关，不等于可反转 H 桥，保持 `RM_FIRE_IN2_ENABLE=0`。

## 上电之前

- 核对 3.3V 高有效、复位/高阻关断、PWM 支持、输入下拉及端子定义；没确认前不接电机。使用小功率假负载验证开机、复位与停止均关断。普通万用表可能看不到 70ms 脉冲，不能据此判触发极性。
- 支路保险、线束、模块和续流器件均按电机启动/堵转电流校核，15A 标签或散热片不代表自动满足；SS54 约 5A，不能保证承受波箱续流。
- 1000µF 电解并 MOS **输入电源端**而不是电机 PWM 输出端，注意极性。104 瓷片可在刷端抑噪；合适的续流二极管条纹端接电机正极、另一端接 OUT-。模块若自带保护，也需核对额定。
- 确认安装允许的电机转向与空载方式；已有固定极性续流二极管后换向，须同步核对二极管在电路中的极性，不能盲目互换整束输出线。

## 软件参数不是机械保证

| 参数 | 当前值 | 含义 |
|---|---|---|
| `RM_FIRE_PWM_HZ` | 100 | 软件 PWM，1ms 节拍下一周期 10 个时隙，有效占空分辨率约 10% |
| `RM_FIRE_SOFTSTART_MS` | 40ms | 占空爬升，不等于限流 |
| `RM_FIRE_SHOT_MS` | 70ms | 单发通电时间初值，不保证恰好一个循环 |
| `RM_FIRE_BURST_MS` | 210ms | 三连发通电初值，不保证恰好三发 |
| `RM_FIRE_COOLDOWN_MS` | 400ms | 单发/三连发结束冷却，连发指令不受同样锁定 |
| `RM_FIRE_MAX_MS` | 3000ms | 连发超时，不是堵转检测 |

当前价格表没有列波箱/电机，实际模块、机械 cut-off 与循环时间也未确认。完成器件规格和线路核对前，不执行 `f 1/2/3`、不接真实负载。之后先完成电路假负载验收，再按厂家允许方式无弹短测；戴护目镜、朝安全方向、保留物理断电。单发/三连发须按实际机构标定；卡住立即断电，不通过延长通电强行排障。

**升级注意：v3.7 修复了旧版实际 10Hz 与标称 100Hz 不一致的问题。PWM 波形已变化，不能沿用旧版实测的单发/三连发标定结论；必须重新测启动电流、温升与循环时间。**

电源采用本次 2S LiPo，不再推荐普通 18650 弹簧盒。独立 MP1584 逻辑路与电容可减轻干扰，但无法保证共享电池深度跌落时不复位；需要测量，不宣称加电容就解决。保险熔断先排查短路、钳位极性和堵转，不直接换更大规格。
