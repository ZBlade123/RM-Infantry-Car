# 引脚与改板说明（旧控制板，v3.8）

本页仅适用于仓库原 F103/TB6612 控制板，完整接线以 [接线总表](接线总表.md) 为准。桌面新 `降压PCB1_2026-11-03` 有不同的 H1/H2/H3/H4 网络，不能按本页针名接线；见 [配件与 PCB 核对](配件与PCB核对.md)。本页不再保留与总线配置冲突的 PWM/视觉接线图。

当前 `RM_GIMBAL_MODE=2`，PB10 输出总线；原项目 PCB 的 PB10 同时通往 RR 方向输入，所以必须断电实测、隔离原走线，再将驱动侧 RR IN1 飞到 PA15。**RR IN2 保留 PB11，不是 PB1**。PA15 已关闭 JTAG，但 SWD PA13/PA14 保留。

两颗 TB6612 各含 A/B 两路，共四路，每轮独立一路，不是同侧两轮并在同一路。STBY 必须为高，先核实板上实际连接。方向 IN1/IN2=10 或 01 换向；代码停车设 00，但 TB6612 PWM 低电平阶段可涉及短路制动，不能承诺整个 PWM 周期始终滑行。

PB10 改为开漏后，需要匹配总线上拉/接口；不接普通 PWM 舵机的 PB0/PA8 座。电源线与信号线不同：H1=5V 逻辑输入，H2=2S 动力输入，舵机单独供电但信号共地。具体电压必须查舵机手册。

本目录没有可重新核验的 `.epro2` 网络表原件，项目此前记录不是实物通断检验。PCB 版本、6P 针序与 STBY 接法必须在断电时核实后才上电。若切回 PWM 模式，须同步恢复 RR 原走线、拆除 PA15 替代连接，不能只改宏。
