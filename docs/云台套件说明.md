# 总线二维云台（v3.7）

采购配置为两颗磁编码总线舵机及金属支架，不能继续套用旧宏科 20KG PWM 舵机的电压、脉宽行程和电流参数。当前固件只实现所附松甲例程的 ASCII 位置协议，**不代表任意总线舵机即插即用**。

## 到货先确认

向卖家索取完整型号、额定电压、两轴启动/堵转电流、TTL/RS485/CAN 接口、上拉/电平电路、波特率、改 ID 指令和角度映射。若不兼容 `#001P1500T0200!`，须换协议驱动/接口后再连接。

MP1584 #1 的计划 5V 只有在舵机允许且带载测试通过后才用。不能因为旧文档写过 6V 就默认新舵机用 6V；也不能默认两轴峰值仅 3A。换 BEC 时按实物电压与峰值选型。

## 当前接口

| 项目 | 配置 |
|---|---|
| 模式 | `RM_GIMBAL_MODE=2` |
| TX | PB10，115200 8N1，开漏，只发 |
| 两轴 | Yaw ID=1，Pitch ID=2；信号共线、供电并联 |
| 电机改线 | RR IN1=PA15，IN2=PB11；隔离旧 PB10 到 IN1 走线 |
| 角度 | 默认跨度 180°、中心 90°，仅待标定值 |
| 反馈 | `g` 是软件指令估计，不是舵机磁编码器实测 |

接线、上拉与改板安全步骤见 [接线总表](接线总表.md)。现有软件保持 TX-only；开漏避免推挽争用，但不意味着已实现回包读取或完整半双工位置反馈。

## 标定

1. 卸下负载/舵盘，限流电源下逐颗确认通信与 ID，优先使用厂家调试器。确认协议兼容后才可用主控 `id 1` / `id 2`，一次仅接一颗；主控会自动发中心指令，注意意外动作。
2. 核对角度跨度，修改 `RM_SERVO_SPAN_DEG` 与两轴中心/限位；首次回中后装舵盘，避免机械中位装错。
3. 从 `y 950`、`s 950` 小步测试，不直接发满行程。Yaw 方向用 `RM_GIMBAL_YAW_INVERT`，Pitch 如需反向须另行实现，当前没有 `RM_SERVO_INVERT` 宏。
4. 两轴同时运动，测供电压降、模块温升、线束和结构间隙，再装实际负载重复测试。撞结构或持续嗡响立即断电，收窄软限位。

v3.7 上电直接请求中心，不再先命令下限；总线首次帧采用 1500ms 插值，之后按斜坡中间值发帧。无位置反馈，不能保证真实慢回中或防撞。若改用 PWM 舵机，模式设 1 并恢复 PCB 方向线路，Yaw=PA8、Pitch=PB0；PWM 首次动作速度尤其不能靠指令斜坡保证。
