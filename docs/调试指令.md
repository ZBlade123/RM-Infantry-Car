# 调试指令手册

串口：蓝牙 HC-05，**9600 8N1**（PA9=TX、PA10=RX，板载 6 脚座）。
用任意串口助手（XCOM / VOFA / PuTTY / 我给的 `tools/rm_send.ps1`）都行。

## 1. 最快上手：发 `p`

```
发: p
收: PONG 1234            ← 1234 = 上电后的毫秒数
```

收到 PONG 说明：供电正常、晶振起振、串口收发正常、主循环在跑。收不到看第 5 节。

## 2. 文本指令（推荐，直接输入）

| 指令 | 作用 | 说明 |
|---|---|---|
| `p` | 握手 | 回 `PONG <ms>` |
| `h` | 帮助 | 打印指令列表 |
| `x` | 急停 | 底盘+发射立即停，云台保持 |
| `v <vx> <vy> <wz>` | 底盘速度 | 三个数 -700~700。例 `v 300 0 0` 前进、`v 0 300 0` 左移、`v 0 0 300` 左转 |
| `s <deg10>` | Pitch 角度 | 单位 0.1°，`s 900`=90.0°；范围 200~1800 |
| `y <deg10>` | Yaw 角度 | 单位 0.1°，`y 900`=90.0°；范围 0~1800（v3.1 新增） |
| `id <n>` | 改总线舵机 ID | 发 `#255PID<n>!` 广播，**线上只接一个舵机时用**。装两个舵机前先把它们分别改成 1 和 2（v3.6） |
| `g` | 云台 + 视觉状态 | 回 `gimbal yaw=90.0 pitch=90.0 homing=0 follow=0`，v3.4 起再回两行 `vision valid=1 mode=1 aim=0 dx=42 dy=-13 frames=120` 和 `vision raw=a 42 -13`（最近一帧原文，非可打印字节显示为 `.`，用来对协议） |
| `aim 0\|1` | 自动瞄准 | 1=按视觉模块的数据转云台，0=手动（默认）。回 `aim on/off`（v3.4 新增） |
| `f 0\|1\|2\|3` | 发射 | 0=停；1/2/3 是软件定时模式（70ms/最长 3s/210ms），不保证实际循环数；未完成机构验收前不要执行 |
| `#<id>P<pwm>T<ms>!` | 套件原始指令 | 例 `#001P2000T500!`，按 pwm(500~2500) 反算角度后执行，标定用 |
| `t 0\|1` | 遥测 | 开/关 100ms 一帧的二进制遥测 |
| `m <轮号> <速度>` | 单轮点动 | 轮号 0=FL 1=RL 2=RR 3=FR，速度 -700~700，例 `m 0 200` |
| `flip <轮号>` | 反转方向 | 只改这一轮的正负号，标定用 |
| `cal` | 打印标定值 | 回 `cal sign +1 +1 -1 -1 trim ... limit ...` 抄回 rm_config.h |
| `keep 0\|1` | 心跳 | 关掉后 500ms 收不到指令就停车（默认开） |

**单键（方便遥控器/键盘直连）**：`w/s/a/d` 前后左右、`q/e/z/c` 斜向、`j/k` 左右转、
`x` 停、`1/2/3` 云台 30°/45°/60°、`f` 三连发、`r` 停发射。
> 注意：单键是"发一次动一下"，`v`/`s`/`f`/`m`/`t` 这些带参数的是多字符指令，两者别混用。

## 3. 二进制帧（给以后写上位机/ROS 用）

```
A5 5A | seq | cmd | len | payload... | crc8
```
- `crc8`：poly 0x07、初值 0，覆盖 `seq..payload`（不含 A5 5A）
- 命令：`0x01` VEL(6B) `0x02` SERVO(2B=只调 Pitch / 4B=Pitch+Yaw) `0x03` FIRE(1B) `0x04` PING `0x05` WHEELTEST(3B)
  `0x06` FLIP(1B) `0x07` TELEM(1B) `0x08` STOP `0x09` CAL `0x0A` REF
- 应答：`0x81` TELEM、`0x82` PONG、`0x83` ACK、`0x84` TEXT

**遥测帧（0x81，20 字节；v3.4 起追加视觉状态）**：
| 偏移 | 类型 | 含义 |
|---|---|---|
| 0-1 | u16 | 电池电压 mV（本版无检测，恒 0） |
| 2-3 | i16 | vx |
| 4-5 | i16 | vy |
| 6-7 | i16 | wz |
| 8-9 | i16 | Pitch 角度 ×10 |
| 10 | u8 | 发射状态 0=IDLE 1=FIRING 2=REVERSE |
| 11 | u8 | 标志位 bit0 链路 / bit1 低压 / bit2 锁定 / bit3 发射中 |
| 12-15 | u32 | 运行毫秒数 |
| 16-17 | i16 | Yaw 角度 ×10（v3.1 新增） |
| 18 | u8 | 视觉状态（v3.4）：bit0-1 模式 0=无 1=相对 2=绝对，bit2 自动瞄准开，bit3 有目标 |
| 19 | u8 | 保留（恒 0） |

例：`t 1` 后每 100ms 收一帧；用 `tools/rm_remote.py` 的 `decode_telem()` 直接解。

### 云台系驱动 `follow`（v3.2）

默认关（沿车头走）。开了以后 `v` 的 vx/vy 按**炮口方向**解释：

| 操作 | follow 0 | follow 1（炮口在 90°=正前） | follow 1（炮口转到 180°） |
|---|---|---|---|
| `v 300 0 0` | 车头向前 | 车头向前 | 车身向左侧移 |
| `v 0 300 0` | 车身左移 | 车身左移 | 车尾向前（倒退） |

用途只有一个：**瞄着目标横移/拉枪线时不把炮口带偏**。落地验证：

1. `y 900`（回中）→ `v 300 0 0`，车应该往前走。
2. `y 1800`（炮口转到一边）→ 再 `v 300 0 0`，车应该朝**炮口指的那边**走。
3. 方向反了就把 `RM_CHASSIS_FOLLOW_SIGN` 改 `-1` 重编（不要改 `RM_GIMBAL_YAW_INVERT`，那个管舵机）。
4. 不想用了 `follow 0`，不用重编译。

> 注意：角度用的是**舵机指令角**，不是实测角（没有陀螺/编码器）。舵机被外力顶偏时，车会按"你以为它在哪"去走。

## 4. 标定流程（仅限已核对的旧 F103/TB6612 控制板）

新 `降压PCB1_2026-11-03` Gerber 与当前固件尚未完成引脚/电压兼容验证。新板请先按 [配件与 PCB 核对](配件与PCB核对.md) 取原理图并核线，禁止照本节试接。

1. 架空车，`m 0 200` → 看哪个轮子转。若转的不是左前，记下来（轮号与实车不一致时改 `rm_config.h` 的 `RM_DIR_*` 分组或调换 hw 表）。
2. 依次 `m 1/2/3 200`，逐个确认；方向反的 `flip <号>` 后再 `m` 验证。
3. 四轮都正了，`cal`，把打印的 `sign` 写进 `RM_MOTOR_FWD_SIGN`；`trim` 用来补齐直线偏差（±200 以内，哪个轮偏就加/减哪个）。
4. 落地：`v 300 0 0` 直线——往右偏，减小右前/右后 trim 或调 `RM_MOTOR_TRIM`；左移 `v 0 300 0` 能走直线说明麦轮方向对。
5. 云台：`s 300`→`s 1500` 慢慢走一遍 Pitch，`y 0`→`y 1800` 走一遍 Yaw，确认没有卡死、没有撞限位；
   限位在 `RM_SERVO_MIN_DEG/MAX_DEG`（Pitch）与 `RM_GIMBAL_YAW_MIN_DEG/MAX_DEG`（Yaw）。
6. 发射：当前价格表未列波箱/电机，且实际 MOS 拓扑与时序未经验证；**不要执行 `f 1/2/3` 或连接真实负载**。完成 [发射机构验收](发射机构.md) 的器件核对、假负载和机械标定后再测试。

## 5. 故障表（从"最可能"到"最不可能"）

| 现象 | 先查什么 |
|---|---|
| 发 `p` 没反应 | ①蓝牙没连上（手机/电脑配对，9600）②PA9/PA10 接反 ③板子没上 5V 或 3.3V 没有 ④HC-05 模块 KEY 脚没拉低（AT 模式） |
| 收得到乱码 | 波特率不对（9600），或 hex/文本模式选错 |
| 轮子完全不转 | ①**STBY 没接高**（见 docs/引脚与接线.md）②H2 的 2S 动力电源未接 ③方向脚对应错 ④`m` 速度给 0 |
| 只有一个轮不转 | 该轮线没插紧（PH2.0 座）或 PB10~PB13 之一虚焊 |
| 一转就重启 | 5V 被拉垮：舵机没独立供电 / 动力和逻辑共地不良 / 电机启动掉压 |
| 车走不直 | 四个轮的 trim 没标定；或轮子装反（麦轮有方向，左轮/右轮别装混） |
| 云台抖 | 先确认该舵机的额定电压/接口/协议及供电压降，不以旧 PWM 舵机的 5V/3A 经验代替规格 |
| 发射不动 | 先确认外置 MOS 模块端子/触发逻辑与 PB14 接线；不得直接探测或连接未核实的功率负载 |
| 连发一下停 | 正常：连发 3s 上限自动断；单发/三连发打完还有 0.4s 冷却，期间 f 1/f 3 不响应 |

## 6. 电脑端工具

- `tools/rm_send.ps1`：PowerShell 一行发指令 + 等回包（Windows 自带串口 API）：
  ```
  powershell -NoProfile -ExecutionPolicy Bypass -File .\rm_send.ps1 -Port COM5 -Cmd "p"
  ```
- `tools/rm_remote.py`：生成/解析二进制帧、算 CRC8、解遥测帧，跑 `--selftest` 可自检。
  需要 Python（没装的话用串口助手发文本指令就够了，文本指令是给人用的）。

## 7. 比赛前 5 分钟自检

1. 上电，`p` → PONG
2. `cal` → sign 和 trim 与实车一致
3. 架空，四轮各 `m` 一下
4. 落地，`v 300 0 0` 前进 1 米、`v 0 0 300` 转一圈
5. `s 900` 云台归中
6. `f 3` 打三连发（AEG 波箱单发容易停在半压缩位）
7. 关蓝牙，确认 0.5s 内停车（**最后一次**做，做完重新上电）
