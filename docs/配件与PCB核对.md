## 新 PCB 飞针数据可确认的网络

飞针文件给出了部分焊盘网络名。以下是设计数据，不代表实物板已焊好或已导通；插头的 1 脚方向必须按板上方形焊盘/丝印和万用表复核。

| 位号/焊盘 | 文件中的网络名 | 当前能得出的结论 |
|---|---|---|
| DC1-1 | VCC | 该焊盘标为 VCC；输入允许电压和防反接能力未知 |
| DC1-2、DC1-3 | GND | 两脚网络名为 GND |
| H1-1/2/3 | GND / 5V / B0 | 三针接口含 PB0 信号；不是旧文档中假定的“主板 H1 逻辑电源口” |
| H3-1/2/3 | GND / 5V / B1 | 三针接口含 PB1 信号 |
| H4-1/2/3/4 | B10 / B11 / GND / 3.3V | 四针接口暴露 PB10、PB11、GND、3.3V；不得仅凭接口形状把整排接到舵机/外设 |
| H2-1/2 | `$1N128` / `$1N116` | 网络未命名，功能和极性未知，不接电池或负载 |

Gerber 压缩包没有原理图和可编辑工程；丝印图也不能证明接口额定。不要把 `12V` 网名当作已稳压 12V 输出。新板的马达驱动芯片/电流能力、供电输入范围、STBY/使能状态、编码器接口及各接口的物理针序，均需原设计者资料或断电通断/带载测量确认。

## 与当前固件的兼容边界

仓库中的 `Mecanum-Car` 固件仍按原记录的 STM32F103C8T6 + 两颗 TB6612 板编译，轮 PWM 为 PA0~PA3，方向脚为 PA4~PA7、PA15/PB11、PB12/PB13；总线云台 TX 使用 PB10。它**没有**对 2026-11-03 Gerber 做过原理图/引脚映射审查，也没有新板上电验证。

因此：

- 若装的是旧 F103/TB6612 板，按 [接线总表](接线总表.md) 和实际板版本逐点核线。
- 若装的是新 Gerber 板，先取得原理图/BOM/固件引脚表，再逐项对照 `rm_config.h`；所有电源断开时用通断档确认接口网络。未完成映射前，不接电机、云台、MOS 负载或电池，也不要烧入当前固件试错。
- 新板 H4 的 PB11 与当前固件定义的 RR 方向脚冲突。若板上确实将它作为同一信号引出，不能再把该脚接入任何把 PB11 当串口 RX/电源的线束。
- H1/H3 虽分别标出 PB0/PB1，但当前总线云台固件不使用它们作云台 PWM；PB1 仅是可选电池 ADC 输入且默认关闭。禁止把这些针脚按旧接线说明混接。

## 建议实操顺序

每一步通过后再进入下一步。出现电压不符、异常温升、复位、异响或电机不受控，先断总开关并拔电池排查。

1. **清点并标识板卡。** 记录 PCB 正反面照片、版本/丝印、芯片完整型号、各模块额定值；新板与旧控制板分开贴标签。向制板者索取原理图、BOM、接口针序和输入电压范围。Gerber 上有网络名不等于能安全上电。
2. **机械装配。** 先确认还需补 2 个 U 支架；固定电机时检查轴线平行、联轴器锁紧和轮胎旋向，按顶视 X 型安装麦轮。PCB 用尼龙柱抬高，焊点不碰金属底盘；电池固定在不会被螺丝/支架刺穿的位置，线束留应力释放。
3. **断电查线。** 电池、ST-Link、所有电机和舵机全部拔除。用万用表确认 DC1、H1/H3/H4 的指定网络、地线连续性、电源正负无短路；记录每个排针的 1 脚方向。H2 未知网、未识别的 `12V`、未查清的马达输出保持空置。
4. **独立调电源。** 每个 MP1584 先不接板/负载，用限流电源给输入，按目标设备手册调电压并记录输入/输出极性。逻辑路才接已经确认的 5V 输入；云台路先核对舵机额定电压和双轴启动电流，再带假负载测压降与温升。MP1584 的“3A”标称不能当作热态持续电流，模块输出不能并联。
5. **只上逻辑电源并烧录。** 电机、舵机、MOS 和波箱断开。仅在已确认是旧 F103/TB6612 板时，按 SWDIO、SWCLK、GND 接 ST-Link，核对 VTref/外部供电无冲突；Keil F7 编译，0 错误后 F8 烧录。蓝牙串口发 `p` 得到 PONG，发 `h` 应显示 `RM-INFANTRY-CAR 3.8`。新 Gerber 板未核对引脚前不执行此步骤。
6. **旧板逐轮架空测试。** 断电接好一轮并再次检查极性/短路，架空四轮、云台断开。给 H2 动力支路上电后先发 `m 0 200`，紧接 `x`，依次轮号 1、2、3；确认每次只动预期的一轮，记录轮位、方向和电机电流。方向不符用 `flip` 临时校正，再把结果写入 `RM_MOTOR_FWD_SIGN` 重编译。不要捏住转轮测堵转；65% 软件限幅和 15A 主保险都不是单路限流。
7. **底盘低速测试。** 确认四轮映射正确后，短时测试直行、横移、旋转；测驱动、电机、接头和线束温升，检查复位、异味、掉压。稳定后再落地低速运行。编码器 A/B 当前没有接入固件，所以命令数值是占空比，不是转速。
8. **云台单轴后双轴。** 查协议兼容后一次只接一颗、卸掉舵盘/负载并用限流电源设 ID；确认 ID 不冲突后才接两轴。观察 PB10 信号电平/上拉与电源压降，使用小步角度指令标定软限位；没有位置读回时，软件角度不等于实测位置。
9. **最后验收其他支路。** MOS 先以低功率假负载检查上电、复位和失联都关断，再按模块说明核验续流与支路保险；只有波箱型号、堵转电流、机械 cut-off、单发时序和安全方向都已确认后，才接真实负载。测试蓝牙停止心跳的失联停车时保持车供电，另测物理总开关和 2S 低压报警。
