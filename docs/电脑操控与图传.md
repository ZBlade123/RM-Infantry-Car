# PC 端遥控（键盘开车 + 电脑看图传）

> 目标：**不开手机**。电脑看 5.8G/图传画面，同一台电脑用键盘开车。
> 这个脚本零依赖（只用 Windows 自带的 .NET 串口），双击 .ps1 就能跑。

## 1. 两条链路各干什么

```
图传发射(车上) ──5.8G 无线──> 5.8G 接收机 ──HDMI/AV──> USB 采集卡(UVC) ──> 电脑屏幕
                                                             └─ 相机 App / OBS / PotPlayer

电脑蓝牙 ──SPP 配对──> HC-05(车上) ──UART1 PA9/PA10──> STM32
```

- **视频链路**：只影响你看得见看不见，和固件无关。
- **控制链路**：就是蓝牙串口，发 `docs/调试指令.md` 里的文本指令，固件本来就支持。

## 2. 图传怎么进电脑

| 你手上的图传 | 电脑怎么收 | 花钱 |
|---|---|---|
| **官方图传模块**（VT02/VT03 类） | 官方接收端 + PC 客户端；或接收端 HDMI 输出接采集卡 | 客户端免费 |
| **5.8G 模拟图传**（摄像头+发射模块） | **5.8G 接收机（带 AV/HDMI 输出）+ USB 视频采集卡** | 接收机 60~120，采集卡 30~60 |
| **数字图传带 HDMI 输出** | USB 采集卡（UVC 免驱）直插 | 30~60 |
| 图传只带 WiFi（手机 App 那种） | 电脑连它的 WiFi，用 VLC 打开 `rtsp://…` | 0 |

**采集卡是最省事的一招**：买"USB 视频采集卡 HDMI 转 USB"，插上就是一个摄像头，Windows 自带的「相机」App 直接能看，OBS/PotPlayer 也行，**不用装驱动**。

延迟参考（开环模拟图传）：采集卡 + 显示约 60~120ms，够校内赛用；数字图传更低。

## 3. 蓝牙配对（电脑，一次就好）

1. 车上电，HC-05 的 LED 快闪。
2. Windows「设置 → 蓝牙和其他设备 → 添加设备 → 蓝牙」，选 `HC-05`，PIN 码 **1234**。
3. 「设备管理器 → 端口(COM 和 LPT)」里会多出**两个** COM：
   - 名字带「传出 / Outgoing」的 ← **用这个**
   - 名字带「传入 / Incoming」的 ← 不用
4. 记下这个 COM 号（比如 `COM7`），下面直接用。
5. **分不清哪根能通就跑 `-Probe`**：它挨个串口发一句 `p`，回 `RM-INFANTRY-CAR` 的就是传出口。
   ```powershell
   powershell -ExecutionPolicy Bypass -File tools\pc_remote.ps1 -Probe
   ```
   没给 HC-05 上电时，设备管理器里的 COM 是配对残留，会报 `does not exist`，属正常。

## 4. 开车

```powershell
# 列出串口，确认端口号和名字
powershell -ExecutionPolicy Bypass -File tools\pc_remote.ps1 -List

# 正式开（把 COM7 换成你的传出端口）
powershell -ExecutionPolicy Bypass -File tools\pc_remote.ps1 -Port COM7

# 不发数据只练手（不接车也能看看按键映射对不对）
powershell -ExecutionPolicy Bypass -File tools\pc_remote.ps1 -Dry
```

### 键位

| 键 | 作用 |
|---|---|
| **W / S** | 前进 / 后退 |
| **A / D** | 左移 / 右移（麦轮横移） |
| **Q / E** | 原地左转 / 右转 |
| **Shift（按住）** | 速度 ×2（300 → 600） |
| **方向键 ← →** | 云台 Yaw 每次 ±2° |
| **方向键 ↑ ↓** | 云台 Pitch 每次 ±2° |
| **空格** | 三连发（`f 3`） |
| **X** | 急停：底盘停 + 发射停 |
| **R** | 云台回中（`y 900` / `s 900`） |
| **G** | 打印云台 + 视觉状态 |
| **T** | 遥测开/关 |
| **Esc** | 退出（退出前自动急停） |

- 松手自动发 `v 0 0 0`（脚本里 1 拍内检测到没按键就归零），**不会失控跑飞**。
- 发出去/收回来的每一行都打印在下面，能直接看到 `PONG`、`gimbal yaw=…`。
- 固件本身还有两道兜底：`keep 1` 时 500ms 没收到指令就自动停；上电/断蓝牙也是停。

## 5. 只想要图传、想用鼠标键盘当"键鼠"？

那就不是发文本指令了，要接**图传模块的键鼠串口**（`0xA5` 帧协议）。本固件**不做键鼠**：
这块板子的 PA2/PA3 被电机 PWM 占了，USART2 用不了（详见 `docs/接线总表.md` §1）。

两条路：
1. **就用这个键盘脚本**（推荐，零额外硬件）——开车手感足够，还不用买鼠标。
2. 真要用官方键鼠：换板子/飞线把 PWM 迁到 `RM_MOTOR_USE_TIM4=1`（PB6~PB9），再解析 `0xA5` 帧，工作量 1 天起。

## 6. 图传和驾驶的配合建议

- **别把图传画面当唯一视野**：校内赛场地就是 5m 见方，抬头看车比看图传快。图传用来对靶瞄水弹。
- 把图传窗口放在屏幕**左上角**，脚本窗口放右下，手不用来回找。
- 图传画面里贴一条**准星标记**（OBS 加个十字图片）——比在脑子里估中心准得多。
- 图传按模块手册独立稳压供电，H2 只是 2S 电池电压，不是 12V；若设备需要 12V，须另配匹配的电源方案，不能直接 H2。

## 6. 校内赛的图传是裁判系统自带的（别买官方的 VT02）

《RoboMaster 校内赛比赛规则》第 8 节：裁判系统 = **4 块装甲板 + 1 个发射装置（含图传 + 水弹发射器）**，
由组委会统一提供、可借用（押金），**不可自行改装**。

| 项 | 规则原文要点 |
|---|---|
| 图传供电 | 自带电池，或外部 **3.3V**；**严禁 5V，会烧** |
| 装甲板供电 | **5V** |
| 控制数据 | 装甲板主板 **UART** 输出键盘/鼠标指令 → 接主控 |
| 操控方式 | 5.2 **禁止目视场地操控，只能看电脑屏幕上的图传画面** |
| 借用时间 | 通过完整形态考察后才有借用资格 |

所以：**这一阶段不用买图传、不用采集卡**。等借到裁判系统，把 USART1 从"蓝牙文本 9600"
切成"装甲板键鼠 115200 + `0xA5` 帧解析"（`rm_config.h` 一个宏），蓝牙只留作调车用。

## 手机遥控（tools\android-remote）

电脑开车要占一个蓝牙串口，比赛现场更常用手机。仓库内自带一个极简安卓 App：	ools\android-remote\
（APK 也可以直接找我要，或按该目录 README 用 uild.ps1 现场编译）。

- 交互：**按住按钮持续发送**（200ms 重发，避开固件 500ms 失联停车），松手自动发 x。
- 按钮：前进/后退/左移/右移/左转/右转/停止、云台↑↓与归中、单发 、状态 g；速度滑块 100~1000。
- 前提：系统蓝牙里先配对 HC-05（密码 1234）；Android 12+ 首次打开要允许「附近的设备」。
- 与电脑二选一：同一时刻只能有一个 SPP 连接，换端前先断开另一边。
- iPhone 不支持 SPP，用不了。

App 源码、构建方法与指令对照见 	ools\android-remote\README.md。
手机 App（桌面 RM步兵战车遥控.apk v2.1，横屏双摇杆：左下摇杆开车+横移、右下摇杆偏航/俯仰、正中大红键停车、绿键三连发、底部速度档与查状态；点顶部「说明」弹出全部按键用途）内置两套协议，按车上实际烧的固件切换：
- RM (v/x/s) —— 本仓库 v3.6 固件；
- RS05 (@) —— @PING/@ARM/@F @B @L @R @FL @FR @BL @BR/@S/@! 那一套（JDY31 桥接固件，@PING 回 PONG RS05-BT/1）。
