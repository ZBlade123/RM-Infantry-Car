# 310 编码器电机与开环边界（v3.7）

采购价格表只写“MC310 带霍尔编码器”，不能据此确定减速比、额定电压、堵转电流或每圈计数。固件的 `RM_310_*` 未知项现设为 0；收到准确型号规格书前不得拿旧项目 `MC310P20_V74_R13` 的 7.4V、1:20、13 线或 1040 CPR 当作这批电机参数。

## 当前没有速度闭环

PCB 原记录未将四轮 A/B 接入 MCU，固件无四轮编码器采样。所以 `v`、`m` 是逻辑占空比，不是 rpm；买到 6P 编码器排线不能自动启用闭环。线序按 [接线总表](接线总表.md) 断电逐针核验，不按颜色或“双头反向”盲插。

若后续要闭环，须重新核算完整引脚/定时器资源、四组 A/B 输入及电平、方向脚迁移、计数溢出、采样率、PID 与失速保护；TIM3/TIM4 两组正交输入只够两路编码器，**不能按旧文档方案采四轮**。TIM4 PWM 与编码器模式也不能同时占用同一定时器。可以考虑专用四路编码器计数板或资源足够的新主控，但本次不擅自改板架构。

确定 CPR 后，采样周期 10ms 的计数差为 d，则 `rpm = d × 6000 / CPR`，60mm 轮线速度 `v = rpm/60 × π × 0.060`（m/s）。这些换算尚未接入当前开环驱动。

## 驱动边界与实操

两颗 TB6612 共四个 H 桥通道，**每通道一颗电机**，不是一通道并两轮。旧参数单轮堵转 2A，高于约 1.2A 连续能力，必须考虑 PCB 散热和实际负载。`RM_MOTOR_LIMIT=650` 仅限 65% 占空，不能推导峰值恒定在 1.2A，也没有电流反馈。不要手捏轮子堵转测试，15A 总保险保护不了驱动单通道过载。

架空逐轮 `m 0 200` 后 `x`，依次测轮号 1、2、3；实物布局按 FL/RL/RR/FR 对应 0/1/2/3。方向反用 `flip`，`cal` 记录后写回 `RM_MOTOR_FWD_SIGN` 重编译，运行时标定不会自动写 Flash。再低速短时测试前进、横移、旋转与驱动温升，出现停转/异常热立即断电。

当前沿用 7.4V 型号与 2S 电源，满电 8.4V；到货核对电机允许电压，不上 3S，也不能用低占空比为电机超压免责。
