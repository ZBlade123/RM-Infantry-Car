# 电脑端步兵战车控制器设计说明

## 目标

制作 Windows 桌面控制器，供操作者在电脑上用键盘驾驶底盘、用鼠标调整云台，并查看连接与固件状态。首版通过 HC-05 蓝牙串口连接当前 STM32 固件，不实现图传显示或比赛裁判系统链路。

## 依据与现状

- 当前控制板为 STM32F103C8T6 + 双 TB6612，遥控串口为 USART1 PA9/PA10、9600 8N1；电脑需连接 HC-05 的传出 COM 口。
- 固件支持 `A5 5A seq cmd len payload crc8` 二进制帧及文本调试指令。CRC8 多项式为 `0x07`、初值为 `0`，数值采用小端序。PING 回包为二进制 PONG；遥测也为二进制帧，因此接收端要按字节解析，不能假设所有回包都是文本行。
- 固件默认启用 500ms 链路超时停车。当前 PowerShell 工具只在速度变化时发送，持续按住同一方向可能无法维持链路。
- 电机编码器尚未接入；云台角度是软件指令估计值。新 Gerber 板与当前固件的引脚/电气兼容性、发射机构均未完成实物验收。

## 首版范围

- 使用 C# WinForms，面向 Windows 10/11；优先使用 .NET 8 Windows 桌面框架和系统串口 API，不增加第三方运行库。
- 一个主窗口显示串口选择、连接状态、控制状态、云台指令角、遥测可用字段和通信记录；支持离线演练，演练模式只显示待发送命令，不访问串口。
- 键盘映射：W/S 前后，A/D 麦轮横移，Q/E 原地转向，Shift 低/高速档切换，X 急停，Esc 断开并退出。
- 鼠标移动调整云台：按住鼠标右键时按相对移动量控制 Yaw/Pitch；松开右键停止云台增量。所有角度由软件限位，范围以固件配置为准。界面标注为“指令角/估计角”，不显示成实测位置。
- 串口连接后以 50ms 周期持续发送当前底盘速度状态（无按键时发送零速度），避免长按期间触发 500ms 失联停车。周期任务不可因 UI 阻塞而停发。
- 窗口失去焦点、键盘状态异常、鼠标右键释放、用户按急停、串口发送失败或退出时，立即发送 STOP/零速度；发送失败后关闭连接并清空所有按键状态。固件 500ms 失联停车作为最后兜底。
- 发射功能首版锁定，不提供可触发开火的按钮或按键；硬件和波箱完成验收后再单独设计解锁流程。

## 通信

- 使用当前二进制协议：VEL `0x01`（vx/vy/wz 三个 int16）、SERVO `0x02`（Yaw/Pitch 两个 int16，单位 0.1 度）、PING `0x04`、TELEM `0x07`、STOP `0x08`。
- 周期任务发送 VEL；云台目标变化时发送 SERVO；连接建立后发送 PING 并启用 TELEM。发送帧带递增序号并按固件规则校验 CRC8。
- 接收循环在后台运行，识别二进制帧及可能的可读文本；校验帧长度、CRC 和字段范围后更新 UI。PONG 超时标记链路异常，遥测中的电池电压恒为 0 时显示“未接入”，不伪装为实测数据。
- 串口只允许本程序独占；连接时显示端口与 9600 8N1。关闭窗口前先尝试急停，再关闭串口。

## 安全边界

- 控制器只适配经核对的旧 F103/TB6612 板；新 PCB 未验证前不连接实车。
- 首次连接及验证按项目接线文档执行：先断开负载，确认逻辑通信；再架空逐轮低速测试。软件急停不能替代物理总电源开关。
- 上位机的零速发送、焦点丢失停车和固件超时停车是多层保护，不代表已通过实车失联验收。

## 实现取舍

- **PowerShell**：可最快复用现有脚本，但命令行体验不满足集中显示和游戏式操作需求。
- **WinForms（采用）**：与 Windows 串口和键盘输入配合直接，首版开发和维护成本低。
- **WPF**：自定义界面能力更强，但首版需要额外的界面结构与学习成本，暂不采用。

## 验收

- 能枚举并连接串口，明确显示连接/断开/通信超时状态。
- 离线演练时验证键盘、鼠标映射及限位，不产生串口写入。
- 使用协议模拟器验证帧格式、CRC、连续 VEL、PONG/TELEM 收包与错误帧丢弃。
- 窗口失焦、按急停、拔除串口、发送异常和正常退出时均清零控制状态并尝试停车；实体车测试另按接线文档分阶段进行。
- .NET 8 Windows 桌面项目可构建，并附带从源码运行的步骤。

## 待实现者决定

- 采用一个 WinForms 项目，优先保持少文件、少依赖；将串口收发与帧编解码置于 UI 线程之外。
- 鼠标灵敏度、速度档和云台软限位均提供保守默认值；先用离线演练和模拟串口验证，再进入实车测试。
