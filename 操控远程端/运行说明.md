# 电脑端控制器

## 启动

需要 Windows 10/11 和 .NET 8 Desktop Runtime。进入本目录后运行：

```powershell
dotnet run --project RMRemote.csproj
```

生成可双击运行的 Windows 版本：

```powershell
dotnet publish RMRemote.csproj -c Release -r win-x64 --self-contained false
```

程序位于 `bin\Release\net8.0-windows\win-x64\publish\RMRemote.exe`。

## 操作

- 默认进入“离线演练”，键鼠不会写串口。取消勾选后选择 HC-05 的传出 COM 口并连接。
- W/S 前进后退，A/D 横移，Q/E 原地旋转；按住 Shift 或点“高速”切换到高速档，松开 Shift 或点“低速”恢复低速档。
- 在云台区域按住鼠标右键并移动鼠标调整云台；按 R 回中；松开右键保持当前目标角。
- X 或窗口右上角“急停”停车；Esc 停车并断开串口。
- 遥测电池值为 0 时表示主控未接入电压检测，不代表电池电量为 0。
- 发射保持锁定。实体测试前按主目录接线文档完成板型确认、架空测试和逐项验收。

## 协议自测

```powershell
dotnet run --project tests\ProtocolTests.csproj
```

自测覆盖帧构造、CRC、小端 VEL 字段、分片/连续帧、文本与二进制混合接收、错误 CRC 丢弃及遥测解码。
